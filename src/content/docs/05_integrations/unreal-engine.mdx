The Shale plugin for Unreal Engine integrates the review pipeline directly into your modeling and rendering workflow.

## Requirements

- Unreal Engine 4.xxx (Does not work with 5.xx yet)
- Shale account with an active organization

## Installation

1. Download the latest Zip file of the plugin for the version of Unreal Engine you are using
2. Install the plugin based on EPIC Games' plugin installation instructions
 - For per project installation, add it to a Plugins folder in your projects Content folder.
 - For engine level installation, add it to a Plugins folder in you Engine folder.

3. Open your project > Edit > Plugins > enable the shale Plugin
4. Open Shale by going to Window > Shale. Shale should open in your sidebar

For more detailed instructions refer to the [Upload Via Plugin](/03_plugin_upload/overview/)
