## August  2026 <Badge text="Latest" variant="success" />

#### Real-Time Updates #### 
- Notes now appear in real-time for all users viewing the same asset in Shale in the browser

#### Blender and Unreal Engine Plugin Updates #### <Badge text="Updated" variant="tip" />
- Can now export a Flat camera view (non-360), and can leave notes and feedback that translate back to 3D space, works the same as panoramas
- Blender plugin now works on Blender 5.xx
- Unreal Engine plugin now works in 5.8

#### Ongoing Video Updates ####
- We are continuing our work on the video review and collaboration process


#### UI Rework ####
- We've reworked the UI to make things more accesible, and more tablet friendly!
- Multiple items can be approved, rejected or archived at once.
- Simplified asset upload. Drag and drop into a project or existing item.
- Filtering and search is easier to access.
- Customisable viewer side panel layouts. Each layout is saved per asset.
- Improved annotation selection and highlighting.


#### Coming Soon ####
- We will be releasing Rhino and Houdini plugins in the next month or so
- We will have major improvements to video review in the next month or so
